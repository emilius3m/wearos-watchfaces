# Wear OS Watch Faces — E3M Corp (`it.e3mcorp`)

Declarative **Watch Face Format 2** (`android:hasCode="false"`) watch faces for Wear OS smartwatches.

## Watch Faces Included

| Directory | Watch Face | Play Store Package |
| :--- | :--- | :--- |
| [`WatchFaceNixie/`](WatchFaceNixie/) | **NIXIE** — IN-14 Nixie tube digital watch face | `it.e3mcorp.watchface.nixie` |
| [`WatchFaceSolari/`](WatchFaceSolari/) | **SOLARI** — Retro split-flap / Solari board watch face | `it.e3mcorp.watchface.solari` |
| [`WatchFacePalette/`](WatchFacePalette/) | **PALETTE** — Minimal split-flap tiles & live weather | `it.e3mcorp.watchface.palette` |
| [`WatchFace/`](WatchFace/) | **APEX METEO** (`SysHUD`) — Telemetry & 3-day weather HUD | `it.e3mcorp.watchface.syshud` |
| [`WatchFaceEclisse/`](WatchFaceEclisse/) | **ECLISSE** — Experimental eclipse dial | Local / WIP |

Play Store packaging automation and store assets live in [`PlayRelease/`](PlayRelease/).
